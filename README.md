# RED SMS · Ruby

Без аргументов программа запрашивает информацию об аккаунте. Требуется Ruby 2.5+. Сторонние библиотеки не нужны.

Укажите логин и API-ключ из личного кабинета в переменных окружения `REDSMS_LOGIN` и `REDSMS_API_KEY`. Запустите из корня репозитория:

```sh
ruby client_info.rb
```

При успехе API возвращает JSON с объектом `info`. Для этого запроса подпись `sig` вычисляется как MD5 от строки `ts + API_KEY`. Для запросов с параметрами перед `ts` добавляются значения параметров, отсортированных по имени.

## Отправка одного SMS

Задайте в окружении `REDSMS_FROM` (зарегистрированное имя отправителя) и `REDSMS_TO` (свой номер в международном формате). Эта команда отправляет одно платное SMS с текстом «Тестовое сообщение от redsms.ru»:

```sh
ruby client_info.rb send
```

При HTTP 200 сохраните UUID каждого принятого сообщения из `items`; в `errors` могут одновременно быть причины отказа для других номеров. Для проверки статуса подставьте UUID из ответа:

```sh
ruby client_info.rb status UUID
```

При `created`, `moderation` и `progress` можно позже повторить только команду статуса. Для SMS статус `delivered` подтверждает доставку. При HTTP 420 проверьте баланс, при 401 — подпись и разрешённые IP. При тайм-ауте запроса отправки автоматический повтор может создать дубликат.
